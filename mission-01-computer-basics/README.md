## 2. Task / objective
Explain how a computer takes input, processes data, gives output and stores results (IPOS). Identify hardware, software and everyday computer-based systems.

## 3. Work completed

### Task 1.1 — IPOS: taking and sharing a photo

| Stage | What happens in your example? | Hardware / component |
|---|---|---|
| Input | I take the photo using the camera | Camera |
| Processing | The processor handles the image data and applies filters | CPU, RAM |
| Output | The photo is shown on the screen | Display |
| Storage | The photo is saved on the device or uploaded online | SSD, cloud storage |

The camera captures the photo as input. The CPU processes it using memory. The display shows it as output. Then it is stored on the SSD or in the cloud so it can be opened or shared later.

## 5. My understanding
IPOS means a computer first takes input, then processes it, gives output and finally stores the result. In my example, the camera gave the input, the CPU processed the photo, the screen showed the output and the SSD stored it.
Hardware is the physical part of a computer that I can touch, like a keyboard or SSD. Software is the set of programs that run on the hardware, like macOS or VS Code.
The operating system is needed because it manages the hardware and lets applications use the keyboard, screen and storage properly.
