# Exploring the Computer and Building a Mini System Report

## About this project
This repository is my Diwali independent learning assignment, "The Digital Detective". I explored how a computer works, practised Terminal commands, looked at how the operating system manages files and programs, learned how numbers and text are stored, and used GitHub to publish my work. The work is divided into missions 0 to 8.

## Topics explored
- Input, processing, output and storage (IPOS), hardware and software
- Terminal commands, file management, flags and pipes
- Operating system, processes, paths and permissions
- Compilers and interpreters
- Binary, decimal and hexadecimal numbers, and text encoding
- Git, branches and Pull Requests
- Networks, DNS and client-server communication

## How to run the number converter
From the repository folder, run:

```bash
cd mission-05-numbers-data
python3 number_converter.py
```
Type a decimal number when asked, and the program shows it in binary and hexadecimal.

## What I learned
I learned how a computer takes input, processes it, shows output and stores data. I practised the Terminal, saw how the operating system manages processes and permissions, converted numbers between binary, decimal and hexadecimal, and used Git and GitHub to save and share my work.
